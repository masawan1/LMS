1. Apa itu GitHub?

GitHub adalah layanan online untuk menyimpan, mencatat riwayat perubahan, dan membagikan kode/proyek. GitHub dibangun di atas Git, alat version control yang mencatat setiap perubahan file sebagai sebuah "commit".

Di GitHub, proyekmu disimpan dalam sebuah repository (folder proyek online). Selain untuk menyimpan kode, repository ini juga bisa langsung dijadikan website hidup lewat fitur bernama GitHub Pages — inilah yang akan kita praktikkan nanti.

💡

Singkatnya: Git mencatat perubahan di komputermu, GitHub menyimpannya online, dan GitHub Pages mengubah repository itu menjadi alamat website yang bisa dibuka siapa saja.

2. Tiga Berkas Dasar Sebuah Website

Website statis paling sederhana selalu terdiri dari tiga jenis berkas berikut. Ketiganya bekerja sama seperti tubuh manusia: kerangka, pakaian, dan gerakan.

🦴 Kerangka

index.html

Berkas utama yang otomatis dibuka pertama kali. Berisi struktur halaman: judul, paragraf, tombol, gambar — semua elemen konten.

<h1>Halo, Dunia</h1>
<p>Ini paragraf.</p>
<button>Klik</button>
👕 Pakaian

style.css

Mengatur tampilan: warna, ukuran font, jarak antar elemen, tata letak. Tanpa CSS, halaman HTML hanya teks polos hitam-putih.

h1 {
  color: #e8b34c;
  font-size: 2rem;
}
⚡ Gerakan

script.js

Menambahkan interaktivitas: merespons klik, mengubah isi halaman, menghitung, memvalidasi form — tanpa perlu memuat ulang halaman.

document.querySelector("button")
  .addEventListener("click", () => {
    alert("Tombol diklik!");
  });

4. Praktik: Menerbitkan Website ke GitHub

Berikut langkah menerapkan tiga berkas di atas menjadi website yang benar-benar hidup di internet lewat GitHub Pages.

  1. Buat repository baru Masuk ke akun GitHub-mu → klik New repository → beri nama (misalnya tugas-web-kka) → set ke Public → klik Create repository.
  2. Unggah tiga berkasmu Bisa lewat tombol Add file → Upload files di GitHub, atau lewat terminal jika sudah instal Git: 
    git init
git add index.html style.css script.js
git commit -m "upload website pertama"
git remote add origin https://github.com/username/tugas-web-kka.git
git push -u origin main
  3. Aktifkan GitHub Pages Di repository, buka tab Settings → Pages. Pada bagian Branch, pilih main dan folder /root, lalu klik Save.
  4. Buka website-mu Setelah beberapa menit, GitHub akan menampilkan alamat seperti: 
    https://username.github.io/tugas-web-kka/
    Buka alamat itu — website yang tadi hanya berupa tiga berkas di komputermu kini bisa diakses siapa saja.
